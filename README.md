## TiMo3 Portfolio

Built using Astro as a way to learn the framework on the fly.

The film lab lives in its own repo (film-labs) at [lab.timo3.dev](https://lab.timo3.dev); old `/photography/lab/*` links redirect there (`src/pages/photography/lab/[...path].ts`). The film desk on `/photography/` reads its public API when the site builds (`src/utils/film.ts`).
